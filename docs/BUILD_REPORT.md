## 3. Not tested, and why

- **Git commands** (lesson 04, every "save your work" step, release steps in 12 and S1): the run was not allowed any git writes. They run in CI: `tutorials.yml` with `--ci` on Linux, or on your machine with `pixi run test-tutorials --ci`.
- **Docker and Apptainer** (lesson 08, `containers.yml`): Docker was not allowed locally and Apptainer does not run on macOS. The Dockerfile follows Pixi's documented pattern but was not linted (hadolint is not on conda-forge).
- **Linux, WSL2, Windows, Intel macOS**: only one machine was available. Written for, and covered by the OS-matrix workflow.
- **GitHub, Zenodo, Codespaces web steps**: need accounts. So the reference project has no Zenodo DOI (the capstone checker reports 17 of 18 for it).
- **Swap-and-reproduce (lesson 12)**: needs two learners.
- **Interactive steps**: JupyterLab in the browser (lesson 06; the same notebook is tested headless) and `quarto preview`.
- **Slurm profile (lesson 09 extra)**: no cluster here.
- **External links**: only internal links were checked offline; `pixi run check-links-online` runs weekly in CI (B6, I7).
- **CI workflows themselves**: cannot run without a push.
